Задача 3

Первый сценарий хочется поделить на два
1.1 100 виртуальных машин на базе Linux и Windows, общие задачи, нет особых требований
Можно предложить Proxmox. Бесплатное решение, подойдёт как для Linux, так и для Windows
1.2 Преимущественно Windows based-инфраструктура, требуется реализация программных балансировщиков нагрузки, репликации данных и автоматизированного механизма создания резервных копий.
В данном случае Microsoft Hyper-V. Все необходимые инструменты есть, преимущество гомогенной среды Windows
2. Требуется наиболее производительное бесплатное open source-решение для виртуализации небольшой (20-30 серверов) инфраструктуры на базе Linux и Windows виртуальных машин.
Вариант KVM или Proxmox. Небольшое количество ВМ, ОС как Linux так и Windows, отсутствуют какие либо определённые требования.
3. Необходимо бесплатное, максимально совместимое и производительное решение для виртуализации Windows-инфраструктуры.
Так как виртуализация Windows инфраструктуры, то в приоритете Microsoft Hyper-V. Полная совместимость и поддердка всего функционала в рамках экосистемы Microsoft. Не требуется лицензирование гостевых ОС. Лицензия Hyper-V входит в стоимость windows server.
4. Необходимо рабочее окружение для тестирования программного продукта на нескольких дистрибутивах Linux.
Virtualbox от Oracle. Без проблем запустятся ВМ на различных ОС, не требуется больших познаний для создание ВМ, можно сделать Snapshot системы перед тестирвоанием

Задача 4
Проблемы и недостатки
- неудобство администрирования, куча разных консолей для управления ВМ
- трудности с сетевой связностью ВМ между разными гипервизорами
- невозможность автоматической миграции ВМ между гипервизорами
- невозможность горизонтального скалирования ВМ в случае нехватки мощностей в одном из гипервизоров
- проблемы с резервным копированием. Зоопарк систем РК
Если бы была возможность создавать инфраструктуру с нуля, то это обязательно моногенная среда.
